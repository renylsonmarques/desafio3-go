# Solução para o desafio 3 do curso de Go da DIO.me.

## Descrição

Este projeto implementa um jogo simples de **Ping Pong** em Go, usando **goroutines** e **canais** para demonstrar o funcionamento básico de concorrência.

## Funcionalidade

- Alterna entre `Ping` e `Pong` a cada segundo
- Usa duas goroutines comunicando-se por canais
- Executa até completar 10 passos e finaliza com uma mensagem de encerramento
